# Agent Sentinel

A small macOS menu bar app that follows coding-agent tasks, manages sleep protection and can switch to a configured backup hotspot.

**Launch preparation — no public installer or active sales yet.**

- Q1 Glass interface and Eye icon.
- Portuguese (Portugal), English and Spanish.
- Planned offers: EUR 15 lifetime or EUR 5/year, each for up to two Macs.
- Seven-day Pro trial in the app, with no card or automatic charge.
- macOS 14 or later, Apple Silicon.

This repository hosts direct-distribution releases and release notes. Application source code is not published here.

The first beta uses local ad hoc signing and has not been notarized by Apple. macOS may block opening or require additional confirmation. Do not disable security protections.

Hotspot association has been observed; full Internet failover is still being validated. Mobile data must work on the phone. Closed-lid operation without an external display or on battery has not been qualified.
