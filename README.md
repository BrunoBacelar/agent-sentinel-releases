# Agent Sentinel

A macOS menu bar app that follows coding-agent tasks, manages sleep protection and can switch to a configured backup hotspot.

[Website and seven-day trial](https://agent-sentinel.digitalis-0015.chatgpt.site) · [Download the beta](https://github.com/BrunoBacelar/agent-sentinel-releases/releases/tag/v0.4.0-beta.1)

- Q1 Glass interface and Eye icon.
- Portuguese (Portugal), English and Spanish.
- Seven-day Pro trial in the app, with no card or automatic charge; manual idle-sleep control remains free.
- Offers prepared in Polar: EUR 15 lifetime or EUR 5/year, each for up to two Macs. **Sales remain disabled pending merchant review and paid-license testing.**
- macOS 14 or later, Apple Silicon.

This repository hosts direct-distribution installers and release notes. Application source code is not published here. Only the customer installer is distributed; the owner's unrestricted installer is not shared.

The beta uses local ad hoc signing and has not been notarized by Apple. macOS may block opening or require additional confirmation. Do not disable security protections. Helper installation on another Mac has not been qualified.

Hotspot association has been observed; full Internet failover is still being validated. Mobile data must work on the phone. Closed-lid operation without an external display or on battery has not been qualified.
